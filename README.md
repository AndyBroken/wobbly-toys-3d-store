# Wobbly Toys — Playful 3D Toy Store (Concept)

Online toy store for a fictional brand. Every product is a real-time 3D toy that bounces, squashes and stretches like a cartoon.

**Live demo:** https://andybroken.github.io/wobbly-toys-3d-store/

**Features**
- Hero scene with 3D toys that drop in, hop when you tap or hover, and follow the cursor with their eyes
- Shop with age filters. Each product card has its own live 3D model, and adding a toy to the bag sends it flying into the 3D cart icon
- Build-a-Buddy configurator: drag to spin the bear, pick fur color, face and accessories, and stitch a custom name on the tag, with live price
- Slide-out cart with quantity controls and a free-shipping progress bar
- Squash-and-stretch UI animations, confetti, toasts, validated newsletter form
- Fully responsive: mobile menu, 2-column shop and compact layouts on phones, touch-friendly hints, reduced-motion support

**Tech:** Three.js (r160, ES modules from CDN), procedural models (no 3D files), vanilla JavaScript, HTML5, CSS3. No build step: static files, hosted on GitHub Pages.

`?shot` turns off entrance animations for screenshots.

*Concept / demo project. Wobbly Toys is a fictional brand; no orders are placed and no messages are sent.*
